01回响Resonance
"一颗石子落入静水，涟漪是它的回声。"
一个落点 + 三层渐隐的弧线，从角落向外扩展。表达的不是声波本身，而是"声音存在过的证据"。绿色由实到虚，暗示从输入到回响的衰减。

02结晶Crystallize
"声音原本无形，文字是它的晶体。"

03气韵Breath
"言出于气，气止于形。"
一笔流转的弧线，起于角落实点（呼吸的起点），终于另一角的开放（文字的延展）。东方水墨笔意，极简到只剩一笔。16px 仍是一条清晰的曲线。

"两根柱子之间，是声音通过的瞬间。"
两根立柱 + 上方拱形 + 中央一点穿越。借鉴了"鸟居"和"门"的形意——一个从一种存在形式跨入另一种的门槛。哲学性最强。

05跃迁Transition
"无序的呢喃，跃为有序的字符。"
左侧散乱的小点（语音的无序）→ 右侧整齐的点阵（文字的有序）。中间隐约的虚线提示"穿越"。一种"信息从混沌走向秩序"的瞬间。

07留白Silence
"语言的意义，藏在沉默的那一段里。"
几乎闭合的圆环，留一道缺口；中心一点。圆代表完整的句子，缺口代表"停顿"——而真正让话语成为话语的，正是这停顿。最东方、最禅意。

08引文Quotation
"括号之内，是某人说过的话。"
