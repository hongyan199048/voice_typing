A空Void
"圆是说出来的，缺口是没说出来的。"
去掉中心点，环本身收薄。缺口移到右上 60°，像未完成的句号。比原型更克制，更接近日本"圆相 (ensō)"的禅意——空即满。

B应Echo
"一句话出去，半句话回来。"
双环嵌套，外环淡、内环实。两个缺口位于相反方向——意指"声音 → 回响"的循环。比原型更有层次和动势，仍保持留白的内核。

C笔Brushstroke
"一笔写下来，再不回头。"
环改为单笔粗壮笔触，内侧叠一层细暗线模拟"枯笔"质感。缺口宽阔，圆头收笔。最像一笔画完的圆相书法，有人手温度。16px 下气场最足。

D言Utterance
"从沉默的容器里，浮出一个字。"
缺口转到正上方，环内一道短竖+顶端余韵小点，像一缕气息从开口升起。环 = 静默的容器，短线 = 被说出的"一个字"。语意比原型更明确。
四个方向：A 空 最克制 / B 应 最有层次 / C 笔 最有人味 / D 言 语意最明。
